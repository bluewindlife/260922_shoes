# 260922_shoes

maRe maRe SD007451を基準に、黒い通勤・仕事靴を履き心地で比較する個人用WEBカタログです。

## 比較条件

- 用途：通勤・仕事で長時間履く
- 色：黒アッパー
- ヒール：3cm程度まで
- 現在の課題：SD007451は横幅はほぼ合うが、かかと抜け・靴ずれがある
- 選定方針：単純に幅を広げず、前足部の快適性と踵保持の両立を重視
- 評価：かかと保持、長時間疲労、前足部・横幅、クッション、足当たり、歩行安定性
- 総合点は作らず、各項目を10点満点で個別比較
- 価格は履き心地評価に含めない
- 商品写真・仕様・レビューはメーカー／ブランド公式情報を優先し、日本語レビューを補助情報として使用
- 在庫・価格の調査基準日：2026-09-23
